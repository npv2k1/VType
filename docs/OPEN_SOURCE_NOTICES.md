# Open-source references

VType's source code in this repository is an original implementation released
under MIT. No source file from the projects below is copied into VType.

## XKey

- Repository: https://github.com/xmannv/xkey
- License: MIT
- Referenced ideas: native Swift/SwiftUI, CGEvent + InputMethodKit dual mode,
  application-specific output strategies.

## Caffee

- Repository: https://github.com/khanhicetea/Caffee
- License: GPL-3.0
- Referenced only at the behavioral/architectural level: a small native menu-bar
  app, direct keyboard listening/sending, mode per application.
- No GPL source is included.

## UniKey and OpenKey

- UniKey: https://www.unikey.org
- OpenKey: https://github.com/tuyenvm/OpenKey
- Referenced for public Telex behavior and compatibility lessons only.
